# 家庭借款 Offset（对冲）计算

A single-page calculator: money borrowed from a lender in China is placed in an Australian home-loan offset account, and repaid in AUD with interest.
It shows the borrower's saving, the lender's return, and how an AUD fall against RMB changes the lender's result.

Tax is not included. Exchange rates and transfer costs are editable estimates.

Live page: https://linusquan.github.io/family-loan-offset-calc/
